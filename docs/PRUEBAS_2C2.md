# PRUEBAS 2C-2

## frmInventario (19 controles)
- Filtro bajo stock mínimo: muestra productos con stock menor al umbral definido.
- Costos ocultos para no-Admin: columnas de precio_costo solo visibles para rol Admin.
- Movimientos E/S/A: permite registrar entradas, salidas y ajustes con validación de stock negativo.
- Volcado a hojas Productos/Inventario: botón para exportar catalogo y movimientos a hojas de cálculo.

## frmVenta (15 controles)
- Carrito multi-ítem: permite agregar múltiples productos con validación de stock en tiempo real.
- Cálculo de IVA 19%: desglosa subtotal, IVA y total.
- Emisión de boleta B-XXXXXX: genera número de boleta secuencial con formato B-XXXXXX.
- Volcado a hojas Ventas/Boletas: guarda la venta y la boleta en las hojas correspondientes.
